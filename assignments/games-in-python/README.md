
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras usando strings, loops e entrada de dados do usuário em Python. Você vai praticar manipulação de strings, loops, condicionais e seleção aleatória.

## 📝 Tarefas

### 🛠️ Criar o Jogo da Forca

#### Descrição
Crie um jogo da Forca onde os jogadores adivinham letras para revelar uma palavra oculta antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Aceitar palpites de letras e mostrar o progresso atual (formato `_ _ _`)
- Rastrear tentativas incorretas restantes
- Encerrar quando a palavra for adivinhada ou as tentativas esgotarem
- Exibir mensagens de vitória/derrota
